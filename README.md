# 2026年度 清教学園高等学校 文化祭 公式鑑賞ガイド (SG fes Viewing Guide)

清教学園高等学校 文化祭の公式ウェブ鑑賞ガイドシステムです。
来場者のみなさまが、スマートフォンやPCからリアルタイムに企画情報や待機時間、タイムテーブル、校内マップ等を確認できるPWA対応Webアプリケーションです。

---

## 🌟 主な機能一覧

### 1. リアルタイム混雑・待機時間モニター (Live Congestion Sync)
- **各教室の待機時間可視化**: 高校1年・2年の全21クラス企画の混雑状況（空きあり / やや混雑 / 混雑中 / 整理券制）と推定待ち時間をリアルタイム表示。
- **Google Apps Script (GAS) 自動同期**: 運営本部および各クラスのスプレッドシートと双方向・自動で最新状態を同期。
- **大画面デジタルサイネージ機能 (Monitor View)**: 校内の大型テレビモニターやプロジェクターに全画面で待機状況・案内を常時自動スクロール投影可能。

### 2. クラス企画一覧 ＆ オンライン整理券案内 (Class Exhibits & Digital Tickets)
- **全21企画の検索・フィルター**: 学年（高1・高2）、ジャンル（劇・体験・展示・飲食・縁日）、校舎（本館・新館）、混雑度別の絞り込み。
- **企画詳細モーダル**: あらすじ・見どころ・タイムスケジュール・注意事項・整理券取得リンク（外部GAS/フォーム連携）を完備。
- **ダイレクトURL対応**: `/project/:id` や `/classes/:id` 形式の個別リンク共有に対応。

### 3. ステージ タイムテーブル (Stage Performance Schedule)
- **第一体育館 ＆ レクチャールーム**: 部活動・有志・クラス公演のスケジュールを時系列表示。
- **進行中バッジ**: 現在上演中・これから・終了のステータスを自動判定。
- **ワンタップ共有**: 演目・時間・場所の案内テキストをクリップボードにコピーして友達にシェア。

### 4. マイタイムライン ＆ スケジュール共有 (My Timeline)
- **カスタム予定表作成**: お気に入りに登録したクラス企画に訪問希望時間を設定。
- **自由予定の追加**: 「昼休み・カフェテリア」「友達と集合」「部活の応援」など自由なスケジュールを組み込み可能。
- **SNS・リンク共有**: LINE・X (旧Twitter) へのワンクリック共有や、友達と共有リンク経由でタイムラインの相互読み込みに対応。

### 5. 校内マップ ＆ 施設案内 (Campus Map & Directory)
- **フロア別案内**: 本館・新館（1F〜4F）のクラス配置図。
- **重要施設の位置案内**: 保健室（救護所）・職員室（本部/落とし物）・お手洗い・給水所・エコステーション（ゴミ箱）を網羅。

### 6. 特別企画・コンテンツ (Special Exhibits)
- **OB・入試希望者向け 校内ツアー**: 見どころを案内するガイド付きツアーの開催時刻・集合場所・案内チラシ。
- **献血コーナー**: 食堂前特設会場の実施要項・オンライン整理券案内。
- **同窓会（清教会）特別企画**: 「未来の仕事図鑑」＆「先輩グルメ」パンフレット閲覧機能。

### 7. よくある質問 ＆ 来場者マナーガイド (FAQ & Manners)
- **重要マナー**: 上履き持参（土足禁止）、校内撮影・SNS投稿マナー、ゴミ分別、飲食エリアのルール。
- **即時キーワード検索**: 気になる疑問をキーワードですぐに検索可能。

### 8. 国際化 ＆ オフライン対応 (i18n & PWA)
- **バイリンガル対応 (日英切り替え)**: 全主要画面を日本語・英語にワンタップで切り替え可能。
- **PWA (Progressive Web Apps)**: ホーム画面に追加してアプリとして起動可能。校内の通信混雑時でもService Workerによるキャッシュで快適に閲覧。

### 9. 運営管理パネル (Admin Management Console)
- **GAS連携URL設定**: 混雑状況・お知らせ配信用スプレッドシートのWeb App URL登録。
- **緊急速報・お知らせ配信**: 本部からのアナウンスをリアルタイムに全端末へプッシュ通知・表示。
- **データのエクスポート・インポート**: 企画・スケジュール等のバックアップおよび一括更新。

## 🛠️ 技術スタック

- **Frontend**: React 18, TypeScript, Vite, Tailwind CSS
- **Animation**: Motion (motion/react)
- **Icons**: Lucide React
- **Hosting**: GitHub Pages (`/Viewing-Guide/` パス完全互換) / Google Cloud Run
- **Data Synchronization**: Google Apps Script (GAS) REST API / LocalStorage Caching

## 🚀 開発・ローカル起動方法

### 必要環境
- Node.js 18.0 以上
- npm

### インストール & 起動
```bash
# 依存パッケージのインストール
npm install

# 開発サーバー起動（ポート 3000）
npm run dev

# プロダクションビルド（GitHub Pages / 配信用）
npm run build
```
